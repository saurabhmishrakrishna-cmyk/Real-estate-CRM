# Real Estate CRM Application

This is a C# Console Application designed to manage Real Estate properties and customer inquiries. It integrates with SQL Server Management Studio (SSMS) to perform CRUD (Create, Read, Update, Delete) operations cleanly and efficiently.

## Features
- *Property Management:* Add, search, view, and delete property listings.
- *Inquiry Management:* Store and manage potential buyer and client inquiries.
- *Database Integration:* Direct connectivity with SQL Server (CRSRealEstateDB).
- *Interactive CLI:* Simple command-line menu for navigation.

## Tech Stack
- *Language:* C# (.NET Framework / .NET Core)
- *Database:* Microsoft SQL Server Management Studio (SSMS)
- *Library:* Microsoft.Data.SqlClient
- *IDE:* Visual Studio Code

## Project Structure
- Program.cs: Main application code containing business logic and SQL connections.
- myproject.csproj: C# project configuration and package dependencies.
